# Code de Conduite — KairoOS

## Notre engagement

Nous nous engageons à faire de KairoOS un espace accueillant pour tous,
quel que soit l'âge, le niveau, la langue ou l'origine.

## Comportements attendus

- Rester courtois et constructif dans les issues, PR et discussions.
- Accepter les critiques avec calme, proposer des solutions.
- Penser aux débutants : expliquer plutôt que moquer.

## Comportements inacceptables

- Insultes, harcèlement, propos discriminatoires.
- Spam, publicité, contenu hors-sujet répété.
- Publication d'informations privées d'autrui.

## Signalement

Contactez l'équipe via GitHub ([@NayrolfRdgs](https://github.com/NayrolfRdgs))
ou Discord (`nayrolf_rdgs`). Tout signalement est traité confidentiellement.

## Sanctions

Non-respect répété → avertissement, puis bannissement temporaire ou définitif
de l'organisation, à la discrétion des mainteneurs.
