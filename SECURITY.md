# Politique de Sécurité — KairoOS

## Versions supportées

| Repo / Version | Supportée |
| :--- | :--- |
| `KairoOS` `0.1.x` | ✅ |
| `kairos-plugins` / `kairos-themes` `main` | ✅ |
| Versions plus anciennes | ❌ |

## Signaler une vulnérabilité

**Ne créez pas d'issue publique.** Contactez directement :
- Discord : `nayrolf_rdgs`
- GitHub : [@NayrolfRdgs](https://github.com/NayrolfRdgs)

Décrivez : repo et version concernés, étapes de reproduction, impact estimé.
Nous accuserons réception sous 72 h et vous tiendrons informé du correctif.

## Périmètre

Sont concernés : l'app (Rust/Tauri, frontend), le protocole IPC des plugins,
le site web. Les plugins/thèmes `community/` sont maintenus par leurs auteurs :
signalez-leur d'abord, escaladez vers l'équipe si pas de réponse sous 14 jours.
